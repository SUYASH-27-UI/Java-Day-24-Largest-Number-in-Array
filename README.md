# Java Day 24 - Largest Number in an Array

This Java program finds the largest number in an integer array using a `for` loop and an `if` statement.

## Example

Array:
```text
12, 45, 23, 67, 30
```

Output:
```text
Largest number = 67
```

## Concepts Used

- Arrays
- Array indexing
- `for` loop
- `if` statement
- Comparison operator `>`
- `numbers.length`

## How It Works

The program stores multiple numbers in an array. It assumes the first element is the largest initially. It then compares the remaining elements and updates the largest value whenever a bigger number is found.
